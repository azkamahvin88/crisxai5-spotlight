An original spotlight card introducing @crisxai5 (https://x.com/crisxai5) as a must-follow AI & crypto expert — AI agents, crypto alpha, Web3 automation — posted on X for make.fun's "Spotlight @crisxai5" bounty. The card was generated and composed in-session by an AI agent: AI-generated background art plus programmatically rendered crisp typography (zero blurry text), phone-readable at 1200×1200.

The post's text carries @crisxai5, the link https://x.com/crisxai5, hashtags #AI #Crypto #AIAgents #Web3, and the entrant's make.fun play code. Places go by the post's likes + reposts + quotes read after the deadline.

## The post

`POST.json` at the repository root names the X post: `{"url": "https://x.com/<handle>/status/<id>"}`.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `POST.json` to `/output/POST.json` — that is all the program does. The house reads the post's counts itself.
